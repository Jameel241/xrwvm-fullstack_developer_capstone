# Cars Dealership — Full Stack Development Capstone

## Project Overview
A full-stack web application for a national car dealership retailer. The application allows users to explore dealership locations, view dealer information, register and log in, submit reviews, and analyze review sentiment.

## Technologies
- Frontend: React, HTML, CSS, JavaScript
- Backend: Django, Python, Flask, Node.js
- Database: SQLite and MongoDB
- Containerization: Docker
- Orchestration: Kubernetes
- Cloud deployment: IBM Cloud Code Engine
- CI/CD: GitHub Actions

## Repository Structure
- `server/djangoapp/` — Django application and microservices
- `server/djangoproj/` — Django project configuration
- `server/frontend/` — React frontend and static pages
- `server/database/` — database files and related resources

## Project Goal
To build, test, containerize, and deploy a full-stack dealership application with dealer information, customer reviews, and sentiment analysis.
